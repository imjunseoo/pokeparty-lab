# 포켓파티 랩 (PokéParty Lab)

보드게임 「**포켓몬 파티!**」(Pokémon Essentials 기반)를 위한 상성 계산기 · 파티 추천기입니다.
포켓몬 이름만 입력하면 **약점 타입**을 알려주고, 가진 포켓몬을 넣으면 **다음에 노릴 속성과 예시 포켓몬**, **멤버별 최선 세팅과 할 일**,
보드 칸마다 **이 칸에 멈추면 할 일**, 야생 칸 후보 3마리 중 **무엇을 잡을지**, 스타팅마다 **추천 파티 조합**, 상대 파티를 넣으면 **선봉**을, 내 기술 세팅으로 **상대별 전투 전략**을 골라줍니다.
하드코딩된 포켓몬 정보 없이 공개 데이터베이스와 게임 데이터에서 뽑은 값만 씁니다.

## 기능

| 화면 | 내용 |
| --- | --- |
| **상대 약점 찾기/포켓몬 검색** | 한글·영문·초성(`ㄹㅈㅁ`)·도감번호 검색 → 받는 데미지 배율, 특성·테라스탈 반영, 내 파티 대면, 실전/추천 세팅, 상성으로 잡기 좋은 포켓몬(게임 출현 지역 표시), 자속 공격 상성 |
| **파티 추천** | 원하는 포켓몬을 고를 수 없는 게임이므로 **추천 속성 + 예시 3마리**(출현 지역, 예시마다 추천 이유 코멘트)를 보여주고, 예시를 고르면 바로 다시 계산. 진화 전 포켓몬은 **최종 진화 기준**(진화 목표 선택), 메가진화 룰이면 **메가진화 모습까지** 평가. **멤버 점수**(전투력 · 파티 기여 · 기본 능력 → 0~100점, 강점·아쉬운 점, 낮은 멤버는 대신 노릴 후보), 6마리가 다 차면 **파티 평가 + 교체 추천**(한 마리만 바꿨을 때 점수가 가장 많이 오르는 조합, 누르면 바로 바꿔 봄), 멤버별 **내 세팅 입력 → 게임 최선 세팅 · 할 일**, 종합 등급·진단, 상세 상성 분석 |
| **칸별 전략** | 상대 차례에 미리 짜 두는 화면. 지금 파티 기준으로 **보드 칸마다 할 일**을 이득이 큰 순서로: 기술 칸(배울 기술 ← 잊을 기술) · 트레이닝 칸(성격·특성·개체값 하나) · 아이템 칸(나온 도구를 누가 지닐지 검색) · 상점(진화도구·지닐 도구·육성 파티 아이템, 꼭 살 것 합계) · 야생 칸(노릴 속성) · 미라클교환(내보낼 멤버) · 마지막 상점(학습장치·이상한사탕·종합민트·특성패치·금색병뚜껑 살 순서). 지금 멈추면 좋은 칸 순위, 게임에서 한 뒤 **했어요**를 누르면 내 세팅에 기록 |
| **전투 전략** | 지금 파티의 **기술 세팅으로 실제 데미지를 계산**한 전투 계획. **상대 포켓몬 대면**(검색·선봉 추천의 상대·`#/battle/<slug>`): 멤버마다 쓸 기술·몇 타·받는 피해·선후공·명중 → 유리/아슬아슬/불리, 레이드 안내 · **상대 타입별 대응**(체육관 관장·트레이너): 18타입마다 공격 1·2순위(기술·1타 비율)와 받기 멤버, 공격 구멍·위험 표시 · **멤버별 운용법**: 기술마다 주력 비율·효과 굉장 타입, 선공 비율, 내보낼 때·조심·받아냄 |
| **포획 추천** | 야생 칸에서 나온 후보 3마리 → 지금 파티에 가장 도움이 되는 포켓몬 (최종 진화·메가진화 기준, 파티가 꽉 차면 바꿀 멤버, 포획 등급별 잡힐 확률) |
| **스타팅 추천** | 게임 시작 때 드래프트로 고르는 스타팅(1~9세대 27마리)마다 추천 파티 조합 3개(최종 진화·메가진화 기준)와 자리마다 "못 잡으면 대신" 후보, 드래프트에 나온 세대만 골라 어떤 스타팅이 좋은지 순위, 고른 조합을 바로 파티로 |
| **선봉 추천** | 상대 파티(최대 6마리, 이름 여러 개 붙여넣기 · **보드 화면 스크린샷** 가능) → 추천 선봉 순위(더블이면 2마리 조합), 경계할 상대와 대응 포켓몬, 대면표 |
| **타입 상성표** | 18×18 상성표, 타입 조합 계산기 |

데이터 기준(상단 선택): **`포켓몬 파티! (게임 룰)`** · `챔피언스 싱글` · `챔피언스 더블(VGC)` · `SV 싱글 OU` 실전 통계 · `타입 상성만(전체 도감)`.

### 「포켓몬 파티!」 게임 룰 반영

- **맵**: 투어(지역별 출현표) · 보드(타입별 칸) · 아울렛(전체) · 아일랜드(세대별) · 메이즈(색깔별) → 추천 예시가 그 맵에서 잡을 수 있는 포켓몬으로 바뀌고 "어디서 나오는지" 표시
- **기믹 룰**: 기본 · 메가진화 · Z기술 · 다이맥스 · 테라스탈 · 모두 · 선착순 · 알로라 → 테라 표시, 메가스톤 안내, 상점에서 살 수 있는 기믹 도구가 달라짐
- **배틀 모드**: 싱글 / 더블 → 세팅·선봉 추천 기준
- **아이템·기술**: 게임 상점·아이템 칸에서 못 구하는 도구, 게임에서 배울 수 없는 기술은 추천 세팅에서 취소선
  - 도구 목록은 게임 아이템 표(`items.dat`)에서 **지닐 수 있는 것만** 씁니다 (중요한 물건·기술머신·로토무카탈로그·메테오라이트 등 쓰는 도구 제외)
  - 도구마다 얻는 곳(배틀 아이템·나무열매 → 아이템 칸·상점 일반 상품, 전용도구 → 상점 전용도구 칸, 메가스톤·Z크리스탈 → 기믹 상점)과 상점 가격 표시
  - 돌격조끼·탈출팩·자석·레드카드·약점보험·맹독/화염/전기구슬은 **같은 이름의 파티 아이템**(보드 효과만, 지닐 수 없음)이 따로 있어 ⚠로 구분 안내
- 미라클교환·레이드 전설 포함 여부, 원작과 다른 게임 종족값 반영, 마지막 토너먼트 Lv.75

### 내 세팅 → 최선 세팅 · 할 일

멤버 카드 위쪽 버튼으로 **계산한 최선 세팅 ↔ Smogon·배틀스타디움·VGC·랜덤배틀 세팅**을 바로 바꿔 볼 수 있고, 세팅마다
"어떤 세팅인지(예: 빠른 칼춤 랭크업) + 왜 좋은지(칼춤으로 공격을 올린 뒤 지진·스케일샷으로 몰아쳐요 · 아이언헤드로 얼음·페어리까지 찔러요)" 한 줄 설명이 붙습니다.
기술·도구·성격은 이름·초성(`ㅈㅈ` → 지진)·타입(`땅`)·능력(`스피드`)으로 **검색해서 입력**합니다.
추천 세팅의 기술을 이 게임에서 못 배우거나 도구를 못 구하면 **대체 기술·도구**를 붙입니다
(같은 역할의 변화기 → 같은 타입·분류 공격기 순, 도구는 화력·스피드·내구 묶음 안에서 점수가 가장 높은 것. 예: 은혜갚기 → 이판사판태클, 기본 룰의 메가스톤 → 생명의구슬).

**추천 도구 (전부 · 구애 빼기 · 없이)**: 게임의 배틀 아이템 84종은 아이템 칸·상점 일반 상품에서 **모두 같은 확률로 무작위**라
(상점 한 곳 한 번 진열에 특정 도구가 나올 확률 약 2.4%) 구애머리띠·구애안경·구애스카프처럼 노린 도구는 구하기 힘듭니다.
세팅 카드 도구 줄 옆(또는 파티 추천의 게임 설정)에서 **구애 빼기**를 고르면 구애 도구 없이 최선 세팅·대체 도구를 다시 고르고,
**없이**를 고르면 도구를 못 구했을 때 기준으로 봅니다. 목표 도구 아래 **못 구하면** 줄에는 대신 지닐 도구(점수 높은 순)와 도구 없이 잃는 점수가 붙습니다.
전용도구 칸은 쓸 수 있는 포켓몬을 가졌을 때만 팔아서(`SIGNATURE_USERS`: 플레이트 → 아르세우스, 전기구슬 → 피카츄 …) 그 포켓몬에게만 추천합니다.

**기술 떠올리기 ON/OFF**: 게임의 기술 칸·학습장치는 「기술 떠올리기」 화면으로 레벨업 기술 + 교배기술 + 가르침·기술머신 기술을 가르칩니다
(`Board_Skill_Tile` `SKILL_TILE_MOVE_SCOPE = 2`, Ultimate Move Tutor `pbGetRelearnableMoves`). 레벨업으로는 못 배우고 떠올리기로만 배우는 기술에는
**떠올리기** 표시가 붙고, 추천 세팅 기술 줄 옆 버튼으로 끄면 레벨업 기술만으로 최선 세팅·대체 기술을 다시 고릅니다 (모든 카드 공통, 저장됨).

파티 추천의 멤버 카드에서 **내 세팅 입력**(레벨 · 기술 4개 · 도구 · 특성 · 성격 · 개체값 31)을 하면, 게임 규칙(노력치 없음, 개체값 20/31,
기술 칸에서 배울 수 있는 기술, 트레이닝 칸의 성격·특성·개체값)으로 **이 게임 최선 세팅**을 계산하고 지금 세팅에서 **이득이 큰 순서의 할 일**
(「기술 칸: 지진 배우기 ← 구멍파기 잊기」, 「트레이닝 칸: 성격 → 고집」 …)을 보여줍니다. 입력한 기술은 파티 공격 범위·선봉 추천에도 반영됩니다.
**개체값은 31을 가정하지 않습니다**: 트레이닝 칸·금색병뚜껑으로 못 올리는 경우가 많아 최선 세팅·참고 세팅·멤버 점수·전투 전략은 지금 개체값(입력 안 하면 기본 20)으로 평가하고,
31로 올렸을 때 오르는 점수는 할 일 맨 끝의 **선택** 한 줄(칸별 전략의 트레이닝 칸·금색병뚜껑)로만 보여 줍니다.

- 점수 = 화력(이 맵 상대 후보에게 기술 하나로 주는 최대 데미지, 100% 상한) − 받는 피해 + 선공 비율 + 변화기·도구·특성 가치(Smogon·랜덤배틀 세팅에 자주 쓰이는 것)
- 데미지는 실제 공식(레벨·실능치·자속·상성·특성·도구·연속기·반동·모으기 등)으로 계산, 습득표는 `site/data/game/moves.json`(세팅 입력을 열 때만 받음)

### 전투 전략

내 세팅 기술을 입력한 멤버는 그 기술로, 아니면 멤버 카드에서 고른 목표 세팅 기술로 계산합니다 (세팅 평가와 같은 데미지 공식, `core/build.js` `duel` · `targetTable`).
상대는 같은 게임 규칙에서 최선 세팅으로 키웠다고 가정하고(레벨 선택 가능), 먼저 쓰러뜨리는 쪽이 이깁니다 (내가 빠르면 내 타수 ≤ 상대 타수, 느리면 <, 선제기 반영).
타수는 맞았을 때 데미지로 세고 명중은 따로 봐서, 필요한 만큼 다 맞을 확률이 85% 아래면 「아슬아슬」. 위협·멀티스케일·돌격조끼·퍼코트 등 반영, 더블이면 범위기는 한 마리당 0.75배.

### 칸별 전략 (이 칸에 멈추면)

멤버 카드에서 고른 목표 세팅(기본 = 계산한 최선 세팅)까지의 할 일을 **칸 종류별로** 모읍니다. 칸 규칙은 게임 스크립트 그대로:
기술 칸은 한 번에 한 마리·기술 하나(`Board_Skill_Tile`), 트레이닝 칸은 성격·특성·개체값 하나 중 하나(`Board_Training_Tile`),
마지막 상점은 5종 중 3종 진열·종류마다 한 번(`TOURNEY_SHOP_ITEMS` · 5,000원, 금색병뚜껑 8,000원), 진화도구 균일가 2,000원, 미라클교환은 반드시 한 마리 교환.
숫자는 멤버 점수가 오르는 정도라 칸끼리 비교할 수 있고, 세팅을 입력하지 않은 멤버는 기술 칸 순위에서 빼고 성격·개체값·도구는 기본값(무보정·20·없음) 기준으로 「세팅 모름」 표시.

### 스크린샷으로 상대 파티 입력

선봉 추천 화면에서 보드 화면 스크린샷을 **파일로 올리거나, Ctrl+V 로 붙여넣거나, 끌어다 놓으면** 왼쪽 플레이어 패널 4개의 파티 아이콘을 읽어
패널마다 "상대로 설정" 할 수 있습니다. 이미지는 브라우저 안에서만 처리되고 서버로 보내지 않습니다.

- 게임 창 캡처(제목 표시줄 포함)·전체화면·창 배율 1~3배·일부만 잘라 낸 화면에서 패널 테두리·초상화 칸·상단 바 그림으로 위치를 자동으로 찾음
- 이로치·기절(붉게 칠해진) 아이콘, 지금 차례라 밝게 칠해진 패널, 빈 칸까지 구분 / 애매한 칸은 주황 테두리 + 후보 목록
- 자동으로 못 찾으면 미리보기에서 **색깔 패널 4개를 드래그로 감싸면** 다시 읽음
- 인식 데이터 `site/data/game/icons.json`(게임 아이콘 1,403개 + 이로치 1,281개 특징값, 보드 화면 템플릿)은 이 기능을 처음 쓸 때만 받음 (압축 전송 약 0.5MB)

## 데이터 출처

- **[PokeAPI](https://github.com/PokeAPI/pokeapi)** `data/v2/csv` — 포켓몬 1025종 + 폼, 한국어 이름, 타입, 종족값, 특성, 타입 상성표
- **[Smogon 사용률 통계](https://www.smogon.com/stats/)** — 최신 월의 기술·도구·특성·성격·테라·동료·카운터 사용률 (한국어로 변환)
- **추천 세팅** — [Smogon 분석가 세팅](https://data.pkmn.cc/sets/) → [Showdown 랜덤배틀 역할 세팅](https://data.pkmn.cc/random/) → 자체 생성(Showdown 습득 기술표 + 종족값) 순으로 모든 포켓몬에 세팅 제공
- **「포켓몬 파티!」 게임 데이터** — 게임 폴더의 `Data/*.dat`(Ruby Marshal)와 보드게임 설정 스크립트에서 출현표·맵·스타팅·룰·아이템·기술 표·습득표·진화·포획 등급을 읽음 (게임 코드는 실행하지 않음).
  스크린샷 인식용 특징값은 `Graphics/Pokemon/Icons`·`Icons shiny`·`Graphics/UI/PokemonParty` 그림에서 만듦
- 이미지: [PokeAPI/sprites](https://github.com/PokeAPI/sprites)

## 로컬 실행

Node.js 20 이상 필요 (외부 패키지 없음).

```bash
npm run data        # PokeAPI·Smogon·세팅 데이터 새로 받기 (선택, 이미 site/data 에 포함됨)
npm run data:game -- --game "C:/…/Pokemon Party!_20261026"   # 게임이 업데이트됐을 때 게임 데이터 다시 뽑기
npm test            # 상성·추천·검색·세팅·게임 데이터 테스트
npm run dev         # http://localhost:5173
```

## 배포

`main` 에 push 하면 `.github/workflows/deploy.yml` 이 테스트 후 `site/` 를 GitHub Pages 로 배포합니다.
매월 3일에 PokeAPI·Smogon·세팅 데이터를 자동 갱신합니다. 게임 데이터(`site/data/game/`)는 게임 파일이 있는 PC에서 `npm run data:game` 으로만 갱신합니다.
