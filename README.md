# 포켓파티 랩 (PokéParty Lab)

보드게임 「**포켓몬 파티!**」(Pokémon Essentials 기반)를 위한 상성 계산기 · 파티 추천기입니다.
포켓몬 이름만 입력하면 **약점 타입**을 알려주고, 가진 포켓몬을 넣으면 **다음에 노릴 속성과 예시 포켓몬**, **멤버별 최선 세팅과 할 일**,
보드 칸마다 **이 칸에 멈추면 할 일**, 야생 칸 후보 3마리 중 **무엇을 잡을지**, 스타팅마다 **추천 파티 조합**, 상대 파티를 넣으면 **선봉**을, 내 기술 세팅으로 **상대별 전투 전략**을 골라줍니다.
하드코딩된 포켓몬 정보 없이 공개 데이터베이스와 게임 데이터에서 뽑은 값만 씁니다.

## 기능

| 화면 | 내용 |
| --- | --- |
| **상대 약점 찾기/포켓몬 검색** | 한글·영문·초성(`ㄹㅈㅁ`)·도감번호 검색 → 받는 데미지 배율, 특성·테라스탈 반영, 내 파티 대면, 실전/추천 세팅, 상성으로 잡기 좋은 포켓몬(게임 출현 지역 표시), 자속 공격 상성 |
| **파티 추천** | 원하는 포켓몬을 고를 수 없는 게임이므로 **추천 속성 + 예시 3마리**(출현 지역, 예시마다 추천 이유 코멘트)를 보여주고, 예시를 고르면 바로 다시 계산. 진화 전 포켓몬은 **최종 진화 기준**(진화 목표 선택), 메가진화 룰이면 **메가진화 모습까지** 평가. **멤버 점수**(전투력 · 파티 기여 · 기본 능력 → 0~100점, 강점·아쉬운 점, 낮은 멤버는 대신 노릴 후보), 6마리가 다 차면 **파티 평가 + 교체 추천**(한 마리만 바꿨을 때 점수가 가장 많이 오르는 조합, 누르면 바로 바꿔 봄), 멤버별 **내 세팅 입력 → 게임 추천 세팅(파티 약점 보충 · 승리 플랜) · 할 일**, 테라스탈·다이맥스 룰이면 **테라스탈·다이맥스 활용**, 종합 등급·진단, 상세 상성 분석 |
| **칸별 전략** | 상대 차례에 미리 짜 두는 화면. 지금 파티 기준으로 **보드 칸마다 할 일**을 이득이 큰 순서로: 기술 칸(배울 기술 ← 잊을 기술) · 트레이닝 칸(성격·특성·개체값 하나) · 아이템 칸(나온 도구를 누가 지닐지 검색) · 상점(진화도구·지닐 도구·육성 파티 아이템, 꼭 살 것 합계) · 야생 칸(노릴 속성) · 미라클교환(내보낼 멤버) · 마지막 상점(학습장치·이상한사탕·종합민트·특성패치·금색병뚜껑 살 순서). 지금 멈추면 좋은 칸 순위, 게임에서 한 뒤 **했어요**를 누르면 내 세팅에 기록 |
| **전투 전략** | 지금 파티의 **기술 세팅으로 실제 데미지를 계산**한 전투 계획. **상대 포켓몬 대면**(검색·선봉 추천의 상대·`#/battle/<slug>`): 멤버마다 쓸 기술·몇 타·받는 피해·선후공·명중 → 유리/아슬아슬/불리, 레이드 안내 · **상대 타입별 대응**(체육관 관장·트레이너): 18타입마다 공격 1·2순위(기술·1타 비율)와 받기 멤버, 공격 구멍·위험 표시 · **멤버별 운용법**: 기술마다 주력 비율·효과 굉장 타입, 선공 비율, 내보낼 때·조심·받아냄 |
| **폼 추천** | 파티 멤버마다 고를 수 있는 **진화 갈래(알로라·가라르·히스이 지방 폼 진화 포함)**와 **폼 변경 도구 폼**(기라티나·디아루가·펄기아 오리진, 원시회귀, 로토무 5폼, 영물폼, 쉐이미 스카이, 굴레를 벗어난 후파, 오거폰 가면, 검왕·방패왕, 테오키스 폼, 아르세우스 플레이트·실버디 메모리 타입, 게노세크트 카세트)을 평균 승률·파티 상성으로 비교해 추천, **이걸로** 누르면 파티 분석·세팅이 그 폼 기준. 얻는 곳(진화도구 칸·전용도구 칸)·가격·지니면/쓰면 바뀌는지 표시 |
| **포획 추천** | 야생 칸에서 나온 후보 3마리 → 지금 파티에 가장 도움이 되는 포켓몬 (최종 진화·메가진화 기준, 포획 등급별 잡힐 확률). 파티가 꽉 차면 후보마다 **멤버별로 바꾼 경우**를 재서 **바꾸기 / 바꾸면 조금 나음 / 바꾸지 말기(잡으면 박스로)** 판단 — 내 세팅을 입력해 키워 둔 멤버는 다시 맞추는 수고만큼 더 이득일 때만 바꿈 |
| **스타팅 추천** | 게임 시작 때 드래프트로 고르는 스타팅(1~9세대 27마리)마다 추천 파티 조합 3개(최종 진화·메가진화 기준)와 자리마다 "못 잡으면 대신" 후보, 드래프트에 나온 세대만 골라 어떤 스타팅이 좋은지 순위, 고른 조합을 바로 파티로 |
| **선봉 추천** | 상대 파티(최대 6마리, 이름 여러 개 붙여넣기 · **보드 화면 스크린샷** 가능) → 추천 선봉 순위(더블이면 2마리 조합), 경계할 상대와 대응 포켓몬, 대면표 |
| **타입 상성표** | 18×18 상성표, 타입 조합 계산기 |

데이터 기준(상단 선택): **`포켓몬 파티! (게임 룰)`** · `챔피언스 싱글` · `챔피언스 더블(VGC)` · `SV 싱글 OU` 실전 통계 · `타입 상성만(전체 도감)`.

### 「포켓몬 파티!」 게임 룰 반영

- **맵**: 투어(지역별 출현표) · 보드(타입별 칸) · 아울렛(전체) · 아일랜드(세대별) · 메이즈(색깔별) → 추천 예시가 그 맵에서 잡을 수 있는 포켓몬으로 바뀌고 "어디서 나오는지" 표시
- **기믹 룰**: 기본 · 메가진화 · Z기술 · 다이맥스 · 테라스탈 · 모두 · 선착순 · 알로라 → 테라 표시, 메가스톤 안내, 상점에서 살 수 있는 기믹 도구가 달라짐
- **배틀 모드**: 싱글 / 더블 → 세팅·선봉 추천 기준
- **아이템·기술**: 게임 상점·아이템 칸에서 못 구하는 도구, 게임에서 배울 수 없는 기술은 추천 세팅에서 취소선
  - 도구 목록은 게임 아이템 표(`items.dat`)에서 **지닐 수 있는 것만** 씁니다 (중요한 물건·기술머신·로토무카탈로그·메테오라이트 등 쓰는 도구 제외)
  - 도구마다 얻는 곳(배틀 아이템·나무열매 → 아이템 칸·상점 일반 상품, 전용도구 → 상점 전용도구 칸, 메가스톤·Z크리스탈 → 기믹 상점)과 상점 가격 표시
  - 돌격조끼·탈출팩·자석·레드카드·약점보험·맹독/화염/전기구슬은 **같은 이름의 파티 아이템**(보드 효과만, 지닐 수 없음)이 따로 있어 ⚠로 구분 안내
- 미라클교환·레이드 전설 포함 여부, 원작과 다른 게임 종족값 반영, 마지막 토너먼트 Lv.75

### 폼 추천 (지방 폼 진화 · 폼 변경 도구)

- **지방 폼 진화**(`Board_Evolution`): 기본 폼이 진화하는 대상에 그 지방 폼이 있으면 진화도구 칸의 알로라의가면·가라르의차·히스이의골동품으로 그 폼으로 진화합니다
  (진화 전 포켓몬 자체에 그 지방 폼이 있으면 대상 아님). 이 갈래는 파티 멤버 칸의 **진화 목표**에도 들어갑니다 (예: 마그케인 → 히스이 블레이범).
  게임은 폼 이름만 보므로 피카츄는 「Alola Cap」 폼 때문에 알로라 라이츄로 진화하지 못하고, 피츄는 알로라의가면으로 모자 피카츄가 됩니다 — 판정은 게임 그대로 두고 모자·메가·달마모드로 가는 갈래만 추천에서 뺍니다.
- **폼 변경 도구**: 상점 전용도구 칸(그 포켓몬을 가졌을 때만, 2,000원). 지니면 바뀌는 도구(구슬·백금옥·가면·녹슨 검/방패·플레이트·메모리·카세트)는 세팅의 도구로 고정하고,
  쓰면 바뀌는 도구(로토무카탈로그·비추는거울·그라시데아꽃·굴레의항아리·운석)는 도구 칸을 비워 둡니다. 멤버 칸의 **폼** 선택으로도 바꿀 수 있습니다.
- 심판의뭉치(플레이트) · 멀티어택(메모리) · 테크노버스터(카세트)는 지닌 도구의 타입으로 데미지를 계산합니다.

### 메가진화 추천 (메가진화를 쓰는 룰)

파티 추천 화면의 **메가진화 추천** 카드에서 누구를 메가진화할지 고릅니다 (파티에 하나만).
직접 고른 메가진화가 있으면 그대로 따르고, 없으면 **평균 승률**(상대 플레이어 포켓몬 후보와 1:1로 붙었을 때 먼저 쓰러뜨리는 비율,
내 세팅을 입력했으면 그 기술 · 아니면 모습마다 추천 세팅)이 가장 많이 오르는 멤버를 자동 추천합니다. 파티 상성 변화도 함께 반영해
약점이 크게 겹치면(예: 한카리아스가 있는데 메가리자몽X) 「약점 겹침」을 표시하고 순위를 낮춥니다.
메가진화한(자동 추천 포함) 멤버는 파티 분석·칸별 전략·전투 전략과 멤버 카드의 **추천 세팅(메가스톤 고정)을 메가진화 모습 기준**으로 계산합니다.
멤버 칸의 메가진화 선택: 자동 추천 · 안 함 · 메가 폼.

### 게임 추천 세팅 · 할 일

이 게임은 도구를 노려서 구하기 어렵고(배틀 아이템 84종이 아이템 칸·상점에 같은 확률로 무작위, 특정 도구가 한 번 진열에 나올 확률 약 2.4%),
개체값·성격·특성은 트레이닝 칸에서 한 번에 하나씩만, 기술머신·기술 칸 기술도 확정으로 못 얻습니다. 그래서 **추천 세팅은**:

- **도구 없이** 계산 (메가스톤·지니면 폼이 바뀌는 도구처럼 정해진 도구만 고정). 구하면 좋은 도구는 「구하면 …」 한 줄로 따로
- **지금 개체값·성격·특성 그대로** (입력 안 하면 개체값 20 · 무보정). 바꾸면 오르는 성격·특성·개체값은 **(선택)** 으로만 보여 줌
- **기술 4개만 고름**: 상대 플레이어 포켓몬 중 **내 파티(팀원)가 못 찌르고 파티 여럿이 약한 상대**를 더 무겁게 쳐서 파티 약점을 메우고,
  **승리 플랜**(1타로 쓰러뜨리는 상대 비율, 칼춤·용의춤·껍질깨기 같은 랭크업 한 번 뒤 1타 비율 · 위험한 배북은 감점)이 분명한 조합
- **레벨업 기술 우선**: 기술 칸·기술머신·가르침으로만 배우는 기술은 구하기 어려운 만큼 감점. 대신 「기술 칸·기술머신에서 구하면 ○○ ← △△ 잊기」로 바꿀 기술을 따로 보여 줌
- 카드에 **승리 플랜** 설명: 「칼춤 한 번 뒤 상대의 92%를 1타 · 지진으로 불꽃·전기·바위 상대를 맡아요」처럼

Smogon·배틀스타디움·VGC·랜덤배틀 세팅은 **실전 세팅 참고**(접힌 칸)로만 보여 주고, 추천 세팅 계산에서는 자주 쓰는 기술·특성을 조금 더 쳐 주는 데만 씁니다.
포켓몬 검색의 추천 세팅도 같은 기준(파티 밖 포켓몬이면 파티 전체의 약점 기준)입니다.
기술·도구·성격은 이름·초성(`ㅈㅈ` → 지진)·타입(`땅`)·능력(`스피드`)으로 **검색해서 입력**합니다.
전용도구 칸은 쓸 수 있는 포켓몬을 가졌을 때만 팔아서(`SIGNATURE_USERS`: 플레이트 → 아르세우스, 전기구슬 → 피카츄 …) 그 포켓몬에게만 추천합니다.
돌격조끼·자석·약점보험·탈출팩·레드카드·끈기갈고리손톱·맹독구슬·화염구슬(전용도구 전기구슬)은 같은 이름의 **파티 아이템**(`PARTY_ITEMS`, 보드 전용 · 지닐 수 없음)이 따로 있어서,
추천하는 곳마다 이름 옆에 **「배틀 아이템 칸 것만」** 표시와 안내를 붙입니다 (아이템 칸·상점에서 「배틀 아이템」 칸으로 나온 것만 지닐 수 있음).

**기술 얻는 방법 · 떠올리기 대체**: 추천 세팅의 기술마다 얻는 방법을 표시합니다.
**레벨업**(지금 레벨 이하) 기술은 레벨업 때 놓치거나 잊어도 「내 포켓몬 확인 → 기술 떠올리기」로 언제든 다시 배우고
(Ultimate Move Tutor `pbGetRelearnableMoves`, `MOVETUTOR` 변수 기본 0 → 자기 레벨업 기술 + 첫 진화 단계의 레벨업 기술, 9세대 떠올리기 전용 기술 포함),
**기술 칸** 기술(기술머신·가르침·교배)은 기술 칸·학습장치·기술머신·가르침으로만 배웁니다. 아직 레벨이 안 된 레벨업 기술은 **Lv.N**.
**떠올리기 대체 ON**(기술 줄 옆 버튼, 모든 카드 공통·저장)이면 기술 칸 기술을 못 구했을 때 기술 떠올리기로 대신 배울 레벨업 기술을
「↳ 떠올리기 땅고르기」처럼 옆에 보여 줍니다 (같은 역할 → 같은 타입·분류 순, 세팅 점수가 가장 높은 것, 한 세팅 안에서 겹치지 않게).

파티 추천의 멤버 카드에서 **내 세팅 입력**(레벨 · 기술 4개 · 도구 · 특성 · 성격 · 개체값 31)을 하면 지금 세팅에서 추천 세팅까지 **이득이 큰 순서의 할 일**
(「떠올리기: 껍질깨기」, 「기술 칸: 지진 배우기 ← 구멍파기 잊기」 …)을 보여주고, 성격·특성·도구·개체값은 **선택** 할 일로만 붙입니다. 입력한 기술은 파티 공격 범위·선봉 추천·전투 전략에도 반영됩니다.

- 점수 = 화력(상대 플레이어 포켓몬 후보에게 기술 하나로 주는 최대 데미지, 100% 상한, 파티 약점 상대 가중) − 받는 피해 + 선공 비율 + 승리 플랜 + 변화기·특성 가치 − 구하기 어려운 기술
- 데미지는 실제 공식(레벨·실능치·자속·상성·특성·도구·연속기·반동·모으기 등)으로 계산, 습득표는 `site/data/game/moves.json`(세팅 입력을 열 때만 받음)

### 테라스탈 · 다이맥스 활용 (그 기믹을 쓰는 룰)

- **테라스탈 활용**: 파티 여럿이 겹쳐 약한 타입마다 **누가 어떤 테라 타입으로 막는지** (이미 반감인 멤버 · 메가스톤을 지닌 멤버는 빼고).
  자기 타입이면 「자기 타입」, 아니면 마스터테라주얼(2,000원) 필요, 같이 막는 타입 · 대신 약해지는 타입 표시. 테라피스(3,000원)를 지녀야 하고 한 번 쓰면 사라짐
- **다이맥스 활용**: 멤버마다 다이맥스(3턴 · HP 2배 · 다이맥스 기술 위력)했을 때 상대 플레이어 포켓몬과 1:1 **평균 승률이 얼마나 오르는지** 순위,
  추천 세팅 공격 기술의 다이맥스 기술 추가 효과(다이번 → 쾌청 …), 거다이맥스 모습이 있으면 거다이맥스 기술·효과(다이스프 2,000원). 다이버섯(3,000원)을 지녀야 함

### 전투 전략

내 세팅 기술을 입력한 멤버는 그 기술로, 아니면 멤버 카드의 게임 추천 세팅 기술로 계산합니다 (세팅 평가와 같은 데미지 공식, `core/build.js` `duel` · `targetTable`).
상대는 같은 게임 규칙에서 최선 세팅으로 키웠다고 가정하고(레벨 선택 가능), 먼저 쓰러뜨리는 쪽이 이깁니다 (내가 빠르면 내 타수 ≤ 상대 타수, 느리면 <, 선제기 반영).
타수는 맞았을 때 데미지로 세고 명중은 따로 봐서, 필요한 만큼 다 맞을 확률이 85% 아래면 「아슬아슬」. 위협·멀티스케일·돌격조끼·퍼코트 등 반영, 더블이면 범위기는 한 마리당 0.75배.

### 칸별 전략 (이 칸에 멈추면)

멤버 카드의 게임 추천 세팅까지의 할 일을 **칸 종류별로** 모읍니다. 칸 규칙은 게임 스크립트 그대로:
기술 칸은 한 번에 한 마리·기술 하나(`Board_Skill_Tile`), 트레이닝 칸은 성격·특성·개체값 하나 중 하나(`Board_Training_Tile`),
마지막 상점은 5종 중 3종 진열·종류마다 한 번(`TOURNEY_SHOP_ITEMS` · 5,000원, 금색병뚜껑 8,000원), 진화도구 균일가 2,000원, 미라클교환은 반드시 한 마리 교환.
숫자는 멤버 점수가 오르는 정도라 칸끼리 비교할 수 있고, 세팅을 입력하지 않은 멤버는 기술 칸 순위에서 빼고 성격·개체값·도구는 기본값(무보정·20·없음) 기준으로 「세팅 모름」 표시.

### 스크린샷으로 상대 파티 입력

선봉 추천 화면에서 보드 화면 스크린샷을 **파일로 올리거나, Ctrl+V 로 붙여넣거나, 끌어다 놓으면** 왼쪽 플레이어 패널 4개의 파티 아이콘을 읽어
패널마다 "상대로 설정" 할 수 있습니다. 이미지는 브라우저 안에서만 처리되고 서버로 보내지 않습니다.

- 게임 창 캡처(제목 표시줄 포함)·전체화면·창 배율 1~3배·일부만 잘라 낸 화면에서 패널 테두리·초상화 칸·상단 바 그림으로 위치를 자동으로 찾음
- 이로치·기절(붉게 칠해진) 아이콘, 지금 차례라 밝게 칠해진 패널, 빈 칸까지 구분 / 애매한 칸은 주황 테두리 + 후보 목록
- 자동으로 못 찾으면 미리보기에서 **색깔 패널 4개를 드래그로 감싸면** 다시 읽음
- 인식 데이터 `site/data/game/icons.json`(게임 아이콘 1,403개 + 이로치 1,281개 특징값, 보드 화면 템플릿)은 이 기능을 처음 쓸 때만 받음 (압축 전송 약 0.5MB)

## 데이터 출처

- **[PokeAPI](https://github.com/PokeAPI/pokeapi)** `data/v2/csv` — 포켓몬 1025종 + 폼, 한국어 이름, 타입, 종족값, 특성, 타입 상성표
- **[Smogon 사용률 통계](https://www.smogon.com/stats/)** — 최신 월의 기술·도구·특성·성격·테라·동료·카운터 사용률 (한국어로 변환)
- **추천 세팅** — [Smogon 분석가 세팅](https://data.pkmn.cc/sets/) → [Showdown 랜덤배틀 역할 세팅](https://data.pkmn.cc/random/) → 자체 생성(Showdown 습득 기술표 + 종족값) 순으로 모든 포켓몬에 세팅 제공
- **「포켓몬 파티!」 게임 데이터** — 게임 폴더의 `Data/*.dat`(Ruby Marshal)와 보드게임 설정 스크립트에서 출현표·맵·스타팅·룰·아이템·기술 표·습득표·진화·포획 등급을 읽음 (게임 코드는 실행하지 않음).
  스크린샷 인식용 특징값은 `Graphics/Pokemon/Icons`·`Icons shiny`·`Graphics/UI/PokemonParty` 그림에서 만듦
- 이미지: [PokeAPI/sprites](https://github.com/PokeAPI/sprites)

## 로컬 실행

Node.js 20 이상 필요 (외부 패키지 없음).

```bash
npm run data        # PokeAPI·Smogon·세팅 데이터 새로 받기 (선택, 이미 site/data 에 포함됨)
npm run data:game -- --game "C:/…/Pokemon Party!_20261026"   # 게임이 업데이트됐을 때 게임 데이터 다시 뽑기
npm test            # 상성·추천·검색·세팅·게임 데이터 테스트
npm run dev         # http://localhost:5173
```

## 배포

`main` 에 push 하면 `.github/workflows/deploy.yml` 이 테스트 후 `site/` 를 GitHub Pages 로 배포합니다.
매월 3일에 PokeAPI·Smogon·세팅 데이터를 자동 갱신합니다. 게임 데이터(`site/data/game/`)는 게임 파일이 있는 PC에서 `npm run data:game` 으로만 갱신합니다.
