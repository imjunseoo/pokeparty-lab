# 포켓파티 랩 (PokéParty Lab)

보드게임 「**포켓몬 파티!**」(Pokémon Essentials 기반)를 위한 상성 계산기 · 파티 추천기입니다.
포켓몬 이름만 입력하면 **약점 타입**을 알려주고, 가진 포켓몬을 넣으면 **다음에 노릴 속성과 예시 포켓몬**, **멤버별 추천 세팅**,
상대 파티를 넣으면 **선봉**을 골라줍니다. 하드코딩된 포켓몬 정보 없이 공개 데이터베이스와 게임 데이터에서 뽑은 값만 씁니다.

## 기능

| 화면 | 내용 |
| --- | --- |
| **상성 탐색** | 한글·영문·초성(`ㄹㅈㅁ`)·도감번호 검색 → 받는 데미지 배율, 특성·테라스탈 반영, 내 파티 대면, 실전/추천 세팅, 상성으로 잡기 좋은 포켓몬(게임 출현 지역 표시), 자속 공격 상성 |
| **파티 추천** | 원하는 포켓몬을 고를 수 없는 게임이므로 **추천 속성 + 예시 3마리**(출현 지역 표시)를 보여주고, 예시를 고르면 바로 다시 계산. 멤버별 추천 세팅, 종합 등급·진단, 상세 상성 분석(커버리지·방어 상성표) |
| **선봉 추천** | 상대 파티(최대 6마리, 이름 여러 개 붙여넣기 · **보드 화면 스크린샷** 가능) → 추천 선봉 순위(더블이면 2마리 조합), 경계할 상대와 대응 포켓몬, 대면표 |
| **타입 상성표** | 18×18 상성표, 타입 조합 계산기 |

데이터 기준(상단 선택): **`포켓몬 파티! (게임 룰)`** · `챔피언스 싱글` · `챔피언스 더블(VGC)` · `SV 싱글 OU` 실전 통계 · `타입 상성만(전체 도감)`.

### 「포켓몬 파티!」 게임 룰 반영

- **맵**: 투어(지역별 출현표) · 보드(타입별 칸) · 아울렛(전체) · 아일랜드(세대별) · 메이즈(색깔별) → 추천 예시가 그 맵에서 잡을 수 있는 포켓몬으로 바뀌고 "어디서 나오는지" 표시
- **기믹 룰**: 기본 · 메가진화 · Z기술 · 다이맥스 · 테라스탈 · 모두 · 선착순 · 알로라 → 테라 표시, 메가스톤 안내, 상점에서 살 수 있는 기믹 도구가 달라짐
- **배틀 모드**: 싱글 / 더블 → 세팅·선봉 추천 기준
- **아이템·기술**: 게임 상점·아이템 칸에서 못 구하는 도구, 게임에서 배울 수 없는 기술은 추천 세팅에서 취소선
- 미라클교환·레이드 전설 포함 여부, 원작과 다른 게임 종족값 반영, 마지막 토너먼트 Lv.75

### 스크린샷으로 상대 파티 입력

선봉 추천 화면에서 보드 화면 스크린샷을 **파일로 올리거나, Ctrl+V 로 붙여넣거나, 끌어다 놓으면** 왼쪽 플레이어 패널 4개의 파티 아이콘을 읽어
패널마다 "상대로 설정" 할 수 있습니다. 이미지는 브라우저 안에서만 처리되고 서버로 보내지 않습니다.

- 게임 창 캡처(제목 표시줄 포함)·전체화면·창 배율 1~3배·일부만 잘라 낸 화면에서 패널 테두리·초상화 칸·상단 바 그림으로 위치를 자동으로 찾음
- 이로치·기절(붉게 칠해진) 아이콘, 지금 차례라 밝게 칠해진 패널, 빈 칸까지 구분 / 애매한 칸은 주황 테두리 + 후보 목록
- 자동으로 못 찾으면 미리보기에서 **색깔 패널 4개를 드래그로 감싸면** 다시 읽음
- 인식 데이터 `site/data/game/icons.json`(게임 아이콘 1,403개 + 이로치 1,281개 특징값, 보드 화면 템플릿)은 이 기능을 처음 쓸 때만 받음 (압축 전송 약 0.5MB)

## 데이터 출처

- **[PokeAPI](https://github.com/PokeAPI/pokeapi)** `data/v2/csv` — 포켓몬 1025종 + 폼, 한국어 이름, 타입, 종족값, 특성, 타입 상성표
- **[Smogon 사용률 통계](https://www.smogon.com/stats/)** — 최신 월의 기술·도구·특성·성격·테라·동료·카운터 사용률 (한국어로 변환)
- **추천 세팅** — [Smogon 분석가 세팅](https://data.pkmn.cc/sets/) → [Showdown 랜덤배틀 역할 세팅](https://data.pkmn.cc/random/) → 자체 생성(Showdown 습득 기술표 + 종족값) 순으로 모든 포켓몬에 세팅 제공
- **「포켓몬 파티!」 게임 데이터** — 게임 폴더의 `Data/*.dat`(Ruby Marshal)와 보드게임 설정 스크립트에서 출현표·맵·룰·아이템·기술 습득 정보를 읽음 (게임 코드는 실행하지 않음).
  스크린샷 인식용 특징값은 `Graphics/Pokemon/Icons`·`Icons shiny`·`Graphics/UI/PokemonParty` 그림에서 만듦
- 이미지: [PokeAPI/sprites](https://github.com/PokeAPI/sprites)

## 로컬 실행

Node.js 20 이상 필요 (외부 패키지 없음).

```bash
npm run data        # PokeAPI·Smogon·세팅 데이터 새로 받기 (선택, 이미 site/data 에 포함됨)
npm run data:game -- --game "C:/…/Pokemon Party!_20261026"   # 게임이 업데이트됐을 때 게임 데이터 다시 뽑기
npm test            # 상성·추천·검색·세팅·게임 데이터 테스트
npm run dev         # http://localhost:5173
```

## 배포

`main` 에 push 하면 `.github/workflows/deploy.yml` 이 테스트 후 `site/` 를 GitHub Pages 로 배포합니다.
매월 3일에 PokeAPI·Smogon·세팅 데이터를 자동 갱신합니다. 게임 데이터(`site/data/game/`)는 게임 파일이 있는 PC에서 `npm run data:game` 으로만 갱신합니다.

## 구조

```
site/                 정적 웹사이트 (GitHub Pages 배포 대상)
  assets/js/core/     상성 엔진 · 파티 분석/추천/선봉 · 검색 (브라우저/Node 공용)
  assets/js/views/    상성 탐색 · 파티 추천 · 선봉 추천 · 타입 상성표 화면
  data/               pokedex.json, usage/*.json, sets.json, game/pokemon-party.json, game/icons.json(스크린샷 인식)
scripts/              데이터 빌드 스크립트 (lib/marshal.mjs: Ruby Marshal 리더, lib/png.mjs·icons.mjs: 아이콘·HUD 특징값), 개발 서버
test/                 node:test 테스트
```
